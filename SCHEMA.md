# LLM Wiki Schema

This wiki follows the Karpathy pattern for structured, agent-accessible knowledge.

## Directory Structure
- `/` : Root. Contains `index.md` (navigation) and `log.md` (change history).
- `/entities/` : Specific objects, people, or project-specific data (e.g., `brainxio.md`).
- `/concepts/` : General technical workflows, guides, and "how-to" knowledge (e.g., `gpg-signing.md`).
- `/system/` : Infrastructure details, hardware specs, and tool configurations.
- `/queries/` : Useful search patterns or prompt templates.

## Naming Convention
- All files are lowercase with hyphens (`kebab-case.md`).
- Every file starts with a `# Title` and a brief description.
